## Goal
A one-page website for git-dispatch, so kakkoi.dev/links can point at a page instead
of a repository, and newcomers see in ten seconds what it is and how to start.

> Stacked PRs without the stack: code a feature on one branch, ship it as independent PRs, no rebase or force-push.

## Plan
1. `site/index.html` (plus a small stylesheet): what it is, the problem it
   solves, install, a short example, links to the README and docs. Content taken
   from this repo's README so it stays accurate. Black on white like kakkoi.dev,
   system fonts, no third-party scripts or fonts, works on a phone.
2. `.github/workflows/pages.yml`: publish `site/` to GitHub Pages on every
   push to the default branch. Nothing else in the repo changes.
3. A link to the page at the top of the README.
