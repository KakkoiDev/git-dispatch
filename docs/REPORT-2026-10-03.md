## Found while writing the page (not fixed here, owner decision)
These are bugs in the tool or its installer, outside this task, so they are
reported rather than changed. The page avoids both.

1. **The README's one-line remote install is broken.** `install-remote.sh`
   downloads `hooks/commit-msg` and `hooks/prepare-commit-msg`, which do not
   exist on `master` (HTTP 404), so `curl ... | bash` stops with exit 22. It
   also never downloads `lib/*.sh`, which `git-dispatch.sh` sources, so it
   would not work even with the hooks back. The page shows the local install
   (`git clone` then `bash install.sh`), which was run and works.
2. **`git dispatch push all` fails right after `git dispatch project`** with
   "No targets found". `push all` finds targets through
   `branch.<target>.dispatchsource`, which only the old `apply` sets. The
   README Quick Start has exactly this sequence. The page pushes by number
   (`git dispatch push 1`, `2`, `3`), which works and is also in the README.
